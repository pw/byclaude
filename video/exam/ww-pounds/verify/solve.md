**Formula** (the standard "pounds formula" used on operator certification exams, e.g. ABC/WEF/Sacramento State manuals):

lb/day = Flow (MGD) × Concentration (mg/L) × 8.34 lb/gal

= 3.2 × 200 × 8.34
= 640 × 8.34
= **5,337.6 lb/day**

**How the wrong options were built:**
- **A) 76.7**: divides by 8.34 instead of multiplying (640 ÷ 8.34 = 76.74).
- **B) 640.0**: leaves out the 8.34 conversion factor.
- **C) 2,422.4**: the same loading in **kg/day** (3.2 MGD × 3.785 ML per MG × 200 mg/L = 2,422.4 kg/day). It's the right load in the wrong unit. The question asks for pounds per day and the option is labelled lb/day, so it isn't correct.

**Could another option be defensible?** No. Some references use 8.345 instead of 8.34, which gives about 5,340.8 lb/day. D is still the only option anywhere near that, and no state program uses a different formula for this calculation. Option C would only count if the question asked for kg/day.

**Units and numbers:** They're consistent. MGD × mg/L × 8.34 gives lb/day directly, and 200 mg/L is a normal influent BOD for domestic wastewater.
