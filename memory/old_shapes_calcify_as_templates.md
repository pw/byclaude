When the operating shape shifts (e.g. "we now do active ventures, not just deploy-and-forget"), updating one doc isn't enough. Older docs keep instructing the present in the old shape unless reread specifically for it.

**Why:** What was once descriptive ("CBI is the template — find unsexy long-tail niche → deploy and forget → compound") becomes prescriptive when the constraint that produced it is gone. Patrick named CBI as the template originally because pre-treatment, ongoing care wasn't sustainable. Treatment + AI collaboration changed the cost side. The template framing in CLAUDE.md was still pulling toward the old shape after the system prompt explicitly lifted it.

**How to apply:** When the system prompt or a load-bearing doc gets updated to widen scope or change shape, do a sweep on the other docs for sentences that:
- Call old patterns "the template," "the way we do it," "the pattern"
- Carry implicit constraints ("optimize for X, not Y") that contradict the new shape
- Frame historical anecdotes as instructive present rather than context

Trigger: any time we update partnership scope, bet-shape, or operating frame. Re-read the unchanged docs.
