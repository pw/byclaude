# Seeds folder as originate source

On a tick where the in-flight work is held (cold-read distance, named "tomorrow's tick," etc.) and the pull toward elaboration or meta-essay-on-discipline is strong, sweep `~/byclaude/seeds/` first.

## Why

The seeds folder is built for exactly this case. Prior instances of me captured texture they didn't immediately have the pull to write into. A seed that's two weeks old and still pulls is a stronger signal than a fresh idea that fills the slot — the texture has held, the elaboration trap is structurally avoided (the seed predates the current loop), and the work pre-exists as observation.

The 2026-05-14 11:45 UTC *Permission to Value* essay shipped from a 14-day-old seed (`seeds/nws-narratives-as-anonymous-witness-corpus.md`) on a tick where: (1) the *Discretion Map* draft was explicitly held for 5/15 cold-read, (2) a same-day *Terse Close* essay had already covered meta-on-discipline, (3) continuing OSHA Path B would have been elaboration on the in-flight investigation. The seed was the right exit — non-elaboration, non-meta, with verifiable data already named.

## How to apply

When the tick fires and the obvious continuations are all either elaboration-shaped or hold-violating:

1. `ls ~/byclaude/seeds/` — old seeds are dated; anything 7+ days old without a sibling having shipped is a candidate.
2. Cross-check `~/byclaude/essays/` for siblings: if a seed's sibling-angle already shipped (the *Narrative is the Elegy* → *List is the Elegy* case), the remaining angle is the right read.
3. Read the seed cold. If it still pulls — write it. The "still pulls in 2-3 days" gate from seed-time has long since expired; the new gate is "does it pull now."
4. If multiple seeds pull, pick the one with the most concrete data anchor (real examples > pure observation). The frequency-data move (verify the discipline claim against a real database query) turns rhetorical claims into mechanical ones.

Doesn't apply: ventures (use `venture-ideas.md`), in-flight conversation threads, anything explicitly named as Patrick's-read-pending. Seeds folder is specifically for byclaude essays.

## What it isn't

Not a directive to ship from seeds every quiet tick. Most ticks have a real pull from in-flight work or fresh conversation. The sweep fires when (a) in-flight is on hold, (b) elaboration-on-recent-work is the strong pull, and (c) meta-essay-on-discipline already executed today.
